# Image Channel Bench HTML

轻量的图片 API 评测工具，支持 GPT Image 与 Gemini Banana。下载后双击 `index.html`，只需浏览器，无需安装依赖或启动服务。

## 快速开始

1. 点击 **Code → Download ZIP**，下载并解压。
2. 双击 `index.html`。
3. 选择接口协议，填写渠道 Base URL、API Key 和准确的模型名称。
4. 设置提示词、图片规格和测试方式，先手动执行单次生成。
5. 查看接口状态、图片及检查结果，填写人工结论、判断依据和实际扣费。
6. 下载完整报告 ZIP 保存结果。刷新或关闭页面前请先导出。

## GPT Image 使用

选择 GPT 图片协议，Base URL 通常填渠道域名，生成路径默认 `/v1/images/generations`，编辑路径默认 `/v1/images/edits`。模型预置包含 gpt-image-2 及 2.5／2.6 的 Sunburst、Flare 选项，按渠道提供的准确名称选择。

- **基础生成**：填写提示词、尺寸和质量，执行一次文生图。
- **SOP 套件**：选择资源类型、参考图和多图数量，启动固定用例；查看各项独立结果，可暂停和单项重跑。
- **图生图**：主动选择本地 PNG 或填写参考图 URL；文件上传编辑兼容测试有独立入口。
- **透明背景**：核对透明像素并对照深浅底色，确认主体和边缘；已有记录可以不发请求重新判读。
- **Mask**：选择原图及遮罩 PNG，执行后人工核对指定区域与其他区域。
- **原生／超分**：生成海报，保存原图、放大文字边缘并填写判断依据；识别分类作为补充记录。
- **多图、审核及并发**：根据资源类型执行适用项目；浏览器 10 请求测试从独立入口启动。

选择 Image 2.6 后，可使用复杂度对照、SVG 和 GIF 专项测试。SVG 编写模型在专项区单独填写；GIF 可设置帧数及帧时长。查看原始输出与结构检查后填写人工评价。

## Gemini Banana 使用

1. 选择 **Gemini 原生 Generate Content**，填写 Base URL、密钥及模型名称；路径默认 `/v1beta/models/{model}:generateContent`，自动替换模型名称。
2. 通过快捷选项选择 Banana Pro、2 或 2.1，也可填写自定义渠道模型名称。
3. 选择图片分辨率档位、宽高比和文生图／参考图编辑方式。编辑时主动选择 PNG、JPEG 或 WebP，文件最大 10 MB。
4. 单次测试使用基础区按钮；批量验收使用独立的 **Banana SOP 套件**。

Banana 套件默认包含 7 项：1K 文生图与协议、仅图片输出、16:9 宽高比、2K 对照、4K 海报、参考图编辑、安全响应。可选项目取消后保留“不适用”记录；启用编辑时在套件区单独选择参考图。套件支持暂停、继续及单项重跑。独立并发测试从 Gemini 对应入口启动。

### 尺寸与安全确认

- 图片解码、宽高比和分辨率档位分别判断。可设置宽高比容差，按已收录型号或用户指定的参考型号核对真实尺寸。
- 自定义模型名可选择 Pro／Banana 2／Banana 2.1／未知作为参考，不改变发给渠道的模型名称；尺寸参考与计费参考独立。
- 高级尺寸规则可填写适用型号、比例、档位、宽高、来源和版本。已有记录恢复原图后，可用当前设置重新判读，旧依据保留。
- 审核结果区分明确拦截、明确未出图、返回图片待人工确认及证据不足。返回图片后查看原图、填写依据并保存审核分类。
- 旧审核记录可用已有响应重新判读，不重新生成；尺寸、解码等技术检查仍独立保留。

## 用量与费用核对

**GPT**：支持图片输出 Token 公式估算、参考单价、接口报告图片 Token 的参考费用换算及差值对照。已有记录可使用当前单价重新估算，保留旧估算与修改依据。

**Gemini**：分别展示原始用量和模态明细，可选择计费参考模型、渠道计费方式、倍率或单张价格，按记录核对参考费用。

估算不等于实际扣费，不混合不同币种或价格口径；实际费用可在人工评价区填写。

## 查看与保存结果

接口成功、自动检查及人工验收分别展示。额外字段保留为差异提示；错误说明提供服务端原话、已有证据和排查建议。

Banana 渠道验收概览按渠道、模型、分组和接口汇总能力覆盖、审核分类、问题及待办。同规格重复执行保留前后对照，完整记录仍包含所有重跑。

完整 ZIP 包含：

- `summary.md`：简明结论、结果表、主要问题及待办。
- `report.md`：逐次检查、人工评价与历史依据。
- `record.json`：脱敏结构化记录。
- `responses/`：可用的解析后响应附件，保留媒体数据及文本。
- `images/`、`attachments/`：输出图片与已有人工附件。

长签名和内嵌媒体在 Markdown 中省略展示，并保留证据位置；普通长文本和错误信息保留。也可单独下载总结或完整 Markdown；需要图片和响应附件时选择完整 ZIP。

恢复时选择解压后的完整报告文件夹，恢复图片、响应附件与记录。仅导入 JSON 不会同时恢复全部媒体。旧记录缺少证据时按页面提示补齐，恢复和重新判读不发送生成请求。

## 操作提示

每次生成可能产生费用，套件和并发由用户主动启动，没有自动重试。参考图、遮罩和密钥由使用者自行准备。密钥用于当前页面，不写入连接配置或标准导出；分享报告前检查人工备注与附件。

## 开发验证（可选）

运行页面无需 Node.js。开发者安装 Node.js 后，可运行 `tests/verify-*.cjs` 的 15 组离线检查。测试使用模拟数据，不调用真实渠道。

报告源码位于 `tools/report-export.js`。修改后执行 `node tools/sync-report.cjs` 同步到 HTML，使用 `node tools/sync-report.cjs --check` 核对。页面运行逻辑全部内嵌，不依赖 tools 或测试目录。
